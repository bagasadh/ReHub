# ReHub

Repair shop profile and self-service booking app for laptop, PC, and smartphone repairs in Depok. Built with plain HTML, CSS, and JavaScript.

## Features
- **Public site:** before/after repair portfolio, symptom checker with cost estimates, booking form with DP selection and WhatsApp confirmation, and ticket status lookup.
- **Technician area:** active ticket dashboard, live search and status filters, hardware inspection checklist, and customer repair history.
- **Storage:** persists ticket data locally via `localStorage` with initial seed data.

## Run Locally

```bash
python3 -m http.server 8000 --directory web-statis
```

Open `http://localhost:8000` in your browser.
